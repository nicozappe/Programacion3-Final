DESCRIPCIÓN DEL PROYECTO

------------------------

Este proyecto es una Web API desarrollada en .NET 8 / C# que implementa una arquitectura en capas (Controllers, Services, Repositories, Data y Models) para la gestión de productos. Conecta a una base de datos Microsoft SQL Server mediante ADO.NET / Dapper para realizar operaciones CRUD sobre la tabla 'Productos'.



REQUISITOS PREVIOS

------------------

- .NET 8.0 SDK o superior.

- Visual Studio 2022.

- Microsoft SQL Server Management Studio (SSMS).



ESTRUCTURA DE LA BASE DE DATOS

------------------------------

Base de datos: Programacion3

Tabla: Productos



Script de creación:

--------------------------------------------------

CREATE DATABASE Programacion3;

GO

USE Programacion3;

GO



CREATE TABLE Productos (

    Id INT IDENTITY(1,1) PRIMARY KEY,

    Nombre VARCHAR(100) NOT NULL,

    Precio DECIMAL(18,2) NOT NULL,

    Stock INT NOT NULL

);

GO
